### 關鍵洞察解析：
1. **原行程最大隱患 (Plan A)**：Day 2 橫跨福岡、別府、湯布院至宮崎高千穗峽再折返別府，單日拉車高達 7.5~8 小時 (440 公里)。高千穗峽階梯陡峭無法推車、柳川扁舟深蹲上下困難，對嬰兒與拄杖長輩極不友善。
2. **飛熊本順路性評估（極度推薦）**：熊本機場（KMJ）位處九州正中心，至高千穗峽**僅約 60～65 公里（車程 1.3～1.5 小時）**，比起從別府（2.5 小時）或福岡（近 3 小時）**節省 50% 以上車程**！若採「福岡進、熊本出」雙點進出（Open-Jaw），完全不走回頭路，行程順暢度大幅躍升。
3. **機票價格與成本對比**：台北直飛熊本目前由華航與星宇執飛，無廉航競爭，228 連假個人票約 NT$ 19,000～25,000，雖不會比福岡便宜，但省下家人十幾小時的疲憊折磨，綜合性價比極高。

## ✨ 網站功能特色

### 1. 🛠️ 自訂行程工作室 (Custom Itinerary Studio)
* **自由拖曳調序**：支援 HTML5 原生拖曳 (Drag & Drop) 與 ⬆️ ⬇️ 按鈕雙模式，手機、平板與桌機皆能順暢調序。
* **多日靈活編排**：自由新增天數 (Day 1..Day N)、刪除天數、重新命名、設定當日出發時間（如 `08:30`、`09:00`）。
* **停留時間調節**：各景點自由增減停留時間（15 ~ 240 分鐘），即刻觸發時間漣漪更新全日時間表。
* **九州景點庫 (Spot Picker)**：收錄 36+ 處核心景點與交通節點，支援關鍵字即時搜尋、分類篩選（景點、美食、購物、溫泉/旅宿、交通）。
* **私房自訂地點**：支援手動新增自訂餐廳、秘境民宿，自訂經緯度與世代適配備註。
* **多元匯出與備份**：
  * 📋 **一鍵複製完整行程文字**（格式化排版，可直接貼入 LINE 群組或 Notion）。
  * 🖨️ **列印 / PDF 匯出**（專屬 `@media print` 純淨紙本手冊排版）。
  * 📤 **匯出 JSON 備份檔** / 📥 **匯入 JSON 備份檔**。
  * 🔄 **一鍵重置為官方預設**。

### 2. 🚗 九州車程自動計算引擎 (Kyushu Transit Engine)
* **真實路網校準矩陣**：直接內建報告中福岡、別府、湯布院、高千穗、熊本、柳川、門司港等主要路廊實測數據。
* **分區速域與繞行模型**：
  * 大分道/九州道高速公路：均速 75~85 km/h。
  * 阿蘇/高千穗山區公路 (國道218/325號)：多彎陡坡，均速 42 km/h，繞行係數 1.52x。
  * 福岡/熊本市區：均速 26 km/h，考慮紅綠燈與塞車。
  * 短途步行切換：距離 < 0.8 km 時自動切換為步行模式 (4.5 km/h)。
  * 出入停車場與紅綠燈固定緩衝：自動計入 4 分鐘真實緩衝。
* **連鎖時間漣漪推算 (Timeline Propagation)**：設定當日出發時間後，全日所有停靠點的「抵達時刻」、「出發時刻」、「行車距離與車程」及「預估結束時刻」自動連鎖推算。
* **安全警報橫幅**：
  * 🚨 **地獄拉車警報**：單日行車超過 4.5 小時自動發出強烈紅框警告（方案 A Day 2 精準觸發！）。
  * ⚠️ **長途如廁與幼兒作息警報**：單程車程超過 60 分鐘提示停靠道之驛或高速 SA。
